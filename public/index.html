音声会話について

名前の頭文字に「＊」をつけた連絡先は、音声会話になります。「＊」のない連絡先とキーパッドからの発信は、留守番電話になります。
音声会話では、話した内容の文章が、サーバー（Vercel）を通してGoogleのGemini APIに送られます。通話が終わると、この端末の会話の記録は消去されます。利用上限に達したときや通信できないときは、留守番電話に切り替わります。

話し相手の声

※この声の設定は、「＊」の連絡先（読み上げ声）で使われます。
声を追加する方法
iPhone：設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語 から、男性の声（Otoya、Hattoriなど）や高品質版を追加します。
Android：設定 → システム → 言語 → テキスト読み上げ から、日本語の音声データを追加します。

「＊」の連絡先との会話の文章は、Gemini APIに送られます（上の説明を見てください）。通話が終わると、この端末の会話の記録は自動的にすべて消去されます。

マイクと音声認識をオンにする

初めて会話するとき、マイクの許可を求める表示が出たら「許可」を押します。
iPhone：設定 → アプリ → Safari → マイク で「許可」にします（機種により 設定 → Safari → マイク）。あわせて、設定 → 一般 → キーボード → 音声入力 をオンにします。
Android：Chromeのメニュー → 設定 → サイトの設定 → マイク で、このページを「許可」にします。ホーム画面のアプリから使う場合は、設定 → アプリ → Chrome → 権限 → マイク も「許可」にします。
※表示は機種によって少し異なります。ホーム画面のアイコンから開くと音声認識が使えない端末もあります。その場合は、ブラウザで開いてください。
